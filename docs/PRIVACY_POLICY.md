# WinQuickSwitch Privacy Policy

Effective date: August 8, 2026

Publisher: **Andrew Chang**

Contact: **andrew.chang0@outlook.com**

## Overview

WinQuickSwitch is a local Windows utility. The current release does not create
an online WinQuickSwitch account and does not include advertising, analytics,
telemetry, or publisher-operated cloud services.

## Information used by the app

WinQuickSwitch reads information exposed by Windows that is needed to provide
its features, including:

- display configuration and available projection modes;
- audio output and microphone endpoint names and identifiers;
- active application audio-session names and volume state;
- connected Bluetooth and locally wired device names and status;
- wireless radio and taskbar state; and
- shortcuts, favorites, profiles, theme, startup, and other preferences you
  configure.

Some device names or profile names may identify you or your workplace if you
choose identifying names. WinQuickSwitch displays and stores this information
only to provide the features you request.

## Storage and transmission

WinQuickSwitch stores settings and profiles locally for the current Windows
user in:

`%LOCALAPPDATA%\WinQuickSwitch\settings.json`

`%LOCALAPPDATA%\WinQuickSwitch\profiles.json`

The current release does not transmit these files, device information, usage
activity, or personal information to Andrew Chang or a publisher-operated
service. Data remains on the Windows device unless you or Windows copy, back
up, synchronize, or share it.

If you enable **Start WinQuickSwitch when I sign in**, the app stores a startup
entry for the current Windows user. Disable that option before removing a
direct-download copy if you want WinQuickSwitch to remove the entry itself.

## Microsoft Store and Windows

Microsoft may process Store account, purchase, payment, installation,
diagnostic, or update information under Microsoft's own terms and privacy
statement. Windows controls the operating-system APIs and permissions used by
WinQuickSwitch. This policy does not govern data independently processed by
Microsoft or another service you choose to use.

## Retention and deletion

Local settings remain until you reset them, delete the files above, remove the
associated Windows user profile, or Windows removes the packaged app data.
Uninstall behavior can differ between the Microsoft Store package and a direct
EXE build.

## Security

WinQuickSwitch relies on Windows account and file-system protections for local
data. Protect your Windows account and avoid sharing settings or profile files
that contain sensitive device or workplace names.

## Children

WinQuickSwitch is a general-purpose utility and is not directed to children.
The current release does not knowingly collect personal information from
children through a publisher-operated service.

## Changes

This policy may be updated when WinQuickSwitch features or data practices
change. Material changes will be reflected in the policy's effective date and
made available with the app or its Microsoft Store listing.
