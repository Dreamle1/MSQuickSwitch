## Description

WinQuickSwitch is a compact Windows 10 and Windows 11 control widget for people who frequently move between desks, displays, speakers, headsets, and microphones.

Open it from the notification area or with a configurable global shortcut, make the change you need, and return to your work. WinQuickSwitch stays lightweight while hidden and does not require an administrator account for normal use.

DISPLAY CONTROLS

Switch between PC screen only, Duplicate, Extend, and second screen only. WinQuickSwitch shows the current display topology when Windows can identify it and disables unavailable choices.

AUDIO CONTROLS

Choose default playback and recording devices, save favourite speakers and microphones, and control active application volume or mute state. General and communications audio roles can be handled separately when needed.

DEVICES AND WIRELESS

See connected Bluetooth and locally wired devices in a normalized list. Check Wi-Fi and Bluetooth radio state and request a change when supported and permitted by Windows. Direct links open the correct Windows Settings pages for pairing and advanced management.

DESK PROFILES

Save repeatable desk configurations that can include a display mode, playback device, microphone, master volume, and microphone mute state. Apply a profile from the widget, tray menu, or an optional global shortcut, with an in-session undo option.

SHORTCUTS AND TASKBAR TOOLS

Configure shortcuts for the widget, individual panels, display modes, favourite audio devices, and profiles. Show or hide the Windows taskbar and open related display, sound, network, and notification settings directly.

PRIVATE BY DESIGN

WinQuickSwitch has no advertising, account requirement, analytics, telemetry, or publisher-operated cloud service. Settings and profiles stay on the local Windows device.

Designed for Windows 10 version 2004 or later on x64 PCs.

## Product features

1. Switch between PC screen only, Duplicate, Extend, and Second screen only with reliable current-mode detection.
2. Restore the exact Extend layout safely while preserving monitor placement and rotation.

11. Use the standard window, a dimmed per-monitor workspace overlay, or floating Display, Audio, and Devices controls.
12. Arrange overlapping workspace widgets and preserve their position and size separately for each monitor.
13. Create named profiles that combine display mode, playback and microphone endpoints, taskbar state, master volume, and microphone mute.
14. Apply a saved profile in one action or with a global shortcut, with best-effort Undo for the previous setup.
15. Edit, duplicate, pin, assign shortcuts to, and delete locally stored profiles.
16. Control the same complete features from the main window, right-side launcher, and workspace widgets.
17. Choose light or dark themes and manage the resident app from its notification-area menu.
18. Keep settings and profiles local with no account, advertising, analytics, telemetry, or cloud service.

## runFullTrust capability explanation

WinQuickSwitch is a packaged WPF desktop utility that runs at medium integrity to use local Windows APIs for display topology, Core Audio endpoints and application-session volume, Plug and Play device inventory, permission-gated radio controls, taskbar visibility, global shortcuts, notification-area integration, and optional per-user startup. These capabilities are used only for user-initiated local features. WinQuickSwitch does not request elevation, install drivers or services, execute arbitrary commands, transmit device data, or include advertising, analytics, or telemetry.

## Certification notes

WinQuickSwitch targets Windows 10 version 2004 or later on x64 desktop PCs. Launch the app and use its navigation tabs to test Display, Audio, Devices, Options, Profiles, and About. Hardware-dependent controls clearly report unavailable operations or open the appropriate Windows Settings page. The application does not require login credentials, elevation, an online account, or network access.
